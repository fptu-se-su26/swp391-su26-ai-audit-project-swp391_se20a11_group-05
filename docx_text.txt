4. Theory Background
4.1 What is Unit Testing?
Unit Testing is a software testing technique where individual components or functions of a program are tested independently to ensure correctness.
Benefits
Detect bugs early
Improve code quality
Simplify maintenance
Support refactoring
Increase reliability
4.2 What is a Unit Test Framework?
A Unit Test Framework provides:
Test execution engine
Assertion methods
Test reporting
Test organization structure
Examples:
JUnit
NUnit
Jest
PyTest

{
    public int Add(int a, int b)
    {
        return a + b;

Task 5 – Write Unit Test Cases
Example NUnit Test Code
using NUnit.Framework;
namespace CalculatorTests
{
    public class Tests
    {
        private Calculator calculator;
        [SetUp]
        public void Setup()
        {
            calculator = new Calculator();
        }
        [Test]
        public void Test_Add()
        {
            Assert.AreEqual(5, calculator.Add(2, 3));
        }
        [Test]
        public void Test_Subtract()
        {
            Assert.AreEqual(2, calculator.Subtract(5, 3));
        }
        [Test]
        public void Test_Multiply()
        {
            Assert.AreEqual(12, calculator.Multiply(3, 4));
        }
        [Test]
        public void Test_Divide()
        {
            Assert.AreEqual(2, calculator.Divide(6, 3));
        }
        [Test]
        public void Test_Add_Fail()
        {
            Assert.AreEqual(10, calculator.Add(2, 3));
        }
    }
}
